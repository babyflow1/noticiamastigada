Política de privacidade

Última atualização: 26 de novembro de 2026

Esta política explica quais dados a Notícia Mastigada usa, por que usa e como protege esses dados. Ela vale para este site e para o programa "Redação Notícia Mastigada", que o canal usa para publicar os próprios vídeos. Seguimos a Lei Geral de Proteção de Dados (LGPD, Lei nº 13.709/2018).

1. Visitantes do site

  • Este site não tem cadastro, formulário, anúncios nem ferramentas de rastreamento.
  • Não usamos cookies.
  • O site é hospedado no GitHub Pages, que pode registrar dados técnicos de acesso (como endereço IP) por motivos de segurança, conforme a política de privacidade do GitHub.
  • As letras do site vêm do Google Fonts, que recebe o endereço IP de quem abre a página para entregar os arquivos.

2. Quem assiste aos vídeos

Os vídeos ficam no YouTube, Instagram, Facebook e TikTok. Cada plataforma trata os dados de quem assiste de acordo com a própria política de privacidade. A Notícia Mastigada só vê os números gerais que as plataformas mostram a qualquer criador (como visualizações e curtidas), sem dados pessoais.

3. O programa de publicação

O programa "Redação Notícia Mastigada" se conecta às contas oficiais do canal com autorização do dono delas. Ele usa:

  • Google / YouTube: permissão para enviar vídeos e editar título, descrição, capa e data de publicação dos vídeos do próprio canal.
  • Meta (Facebook e Instagram): permissão para ver a lista de páginas e publicar posts e vídeos na página e no perfil do Instagram do próprio canal.
  • TikTok: permissão para ver as informações básicas da conta do canal e enviar vídeos para ela.

O programa não acessa contas de outras pessoas, não lê mensagens privadas e não coleta dados de seguidores.

4. Onde os dados ficam

  • As chaves de acesso ficam guardadas apenas no computador do canal e nunca são compartilhadas.
  • Não vendemos, alugamos nem repassamos dados a ninguém.
  • Os dados são usados só para publicar e organizar os vídeos do canal.

5. Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

6. Como retirar a autorização

A autorização dada ao programa pode ser retirada a qualquer momento nas configurações de cada plataforma:

  • Google: myaccount.google.com/permissions
  • Facebook e Instagram: Configurações, depois "Integrações comerciais" ou "Apps e sites".
  • TikTok: Configurações e privacidade, depois "Segurança" e "Apps e serviços".

Ao retirar a autorização, apagamos as chaves guardadas.

7. Seus direitos

Pela LGPD, você pode pedir para saber se temos algum dado seu, corrigir ou apagar. Na prática, não guardamos dados de visitantes nem de quem assiste. Mesmo assim, é só escrever para o e-mail abaixo.

8. Mudanças nesta política

Se esta política mudar, atualizamos a data no topo da página.
